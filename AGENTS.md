# django-settings-env

`django-settings-env` provides Django-oriented settings helpers built on
`envex`. See the [project README](README.md) for installation, configuration,
and API usage.

## Development handoff

During development, maintain `.todo/context.json` as the handoff document. Keep
it current with the task status, relevant decisions, outstanding work, and any
verification still required so another agent can resume reliably.
